# Prototype evidence

Use this contract whenever a [`chart-work`](/skills/chart-work) decision ticket uses or converts to
the `prototype` evidence path. A prototype is evidence for a decision, not the destination
deliverable.

## Smallest useful comparison

Build only enough to make the contested behavior observable. Keep alternatives side by side or
behind one obvious toggle, then ask the user to perform the shortest meaningful task.

Before resolving the ticket, record:

```text
## Prototype evidence
- Comparison:
- Artifact: <stable inspectable link or repository-relative path>
- Run/verification receipt:
- Observed user reaction:
- User judgment:
- Judgment rationale:
- Retention/disposal status:
```

The artifact remains inspectable through the decision. The run/verification receipt names how the
prototype was exercised and the relevant result. Observed behavior and the user's explicit judgment
with rationale are separate evidence. The retention/disposal status says what remains, or what was
removed after its evidence moved to a stable inspectable artifact.

Frontend prototypes also follow the shared [Frontend mockups](/reference/mockups) contract for
design-system bootstrap, fidelity, states and approval.
