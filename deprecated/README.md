# deprecated

Retired skills live here instead of being deleted — the set visibly evolves. This folder is
outside the plugin's `skills/` root, so nothing here is ever distributed or discovered.
A skill re-enters `skills/` only by passing the definition of done in `writing-skills` again.

The former `guide-me` and `chart-work` entry points are retained here as historical, undistributed
material. Their active planning responsibilities now live in `skills/plan-work/`.
